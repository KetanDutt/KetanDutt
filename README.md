## 👨‍💻 About Me

I'm a game developer from India who loves building playable experiences and exploring new tech — most of my projects ship with a live WebGL demo so you can click and play them right from this page.

- 🔭 **Building:** [Easy Gmail Cleaner](https://ketandutt.github.io/Email-Filter/), an [UNO game in Godot](https://ketandutt.github.io/UNO_Godot/), and game-dev experiments
- 🤖 **Exploring:** AI agents & smart study tools ([Python agent](https://github.com/KetanDutt/SmartStudyAssistantAgent), [GenAI hackathon experiments](https://github.com/KetanDutt/GoogleCloudGenAIHackathon2026)) alongside classic game AI, multiplayer networking, and design patterns
- 🛠️ **Daily drivers:** Unity (C#), Godot (GDScript), Phaser & vanilla JavaScript
- 🤝 **Open to collaborating on:** game jams, open-source games, and game development tools
- 🎯 **Ambition:** one day contribute upstream to a major open-source game engine
- 🎸 **Fun facts:** I draw comics, and jam on the guitar or drums when I'm not debugging `NullReferenceException`s
